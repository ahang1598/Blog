🏗 架构基础（1-7）

1

分层与依赖方向

Schema → Core/Protocol → Server；Client 只能依赖 Schema/Protocol。为何禁止反向依赖，分层失败的真实代价。

系统设计成熟度
2

持久化执行：admission vs execution

两车道 + 中间一条 durable log。崩溃恢复语义；为何 SessionExecution 进程级且按 ID 寻址；drain 为何"advisory"无持久身份。

抗失败设计
3

SystemContext 代数 + epoch 快照

initialize/reconcile/replace；为何对照"已 admit 的快照"做 reconcile 而非每轮重建；不带 epoch 会缓存抖动 / 上下文漂移。

成本与缓存
4

投递语义：steer vs queue

两个 promote 边界；为何 steer 不能打断在途 stream；"any 输入重置 step、批量 steer 只重置一次"的并发理由。

并发与一致性直觉
5

每轮一次 stream + 重载历史

为何"一轮一次 stream"是硬不变式（计费/取消/缓存/错误）；continuation 为何必须从 DB 重投影而非内存拼接。

抗失败 + 缓存
6

请求双层类型 + compile 墙

lenient 输入 vs strict LLMRequest 各自价值；promptCacheKey 省了什么；compile 墙让新增 provider 一文件搞定。含完整 LLMRequest 示例。

成本 + 可扩展
7

Location 隔离 + 工具输出有界

Location-scoped 服务买来什么（多工作区/多 worktree/集群接缝/可测）；为何进程单例会锁死未来；工具输出为何必须有界（上下文爆炸 / 缓存失效 / 噪声淹没信号）。

可扩展 + 成本控制

🤖 智能体与工具（8-11） · 新增

8

智能体架构：把约束打成一个人格

agent = prompt + permission + model + sampling + steps 五维度焊死的命名包。为何约束不可分；mode（primary/subagent/all）；默认 agent 目录；selectable 与默认链。

系统设计 + 安全建模
9

子智能体编排与权限收窄

子 agent 是 task 工具派生的独立 session；权限减法收窄（交集语义）；防递归默认禁；结果 durable 回流而非内存返回；深度限制。

最小权限 + 分布式恢复
10

工具调用全生命周期

执行前先记 Tool.Called；eager 并发结算（FiberSet）；工具崩不了 stream；failUnsettledTools 兜底。含一次 read 调用的完整事件序列示例。

事件溯源 + 容错
11

工具契约与双层权限门

模型看得到（name/desc/schema）vs 看不到（execute/permission）；layer 1 whollyDisabled 删工具，layer 2 调用时按输入 assert（allow/deny/ask）。deny>ask>allow 单调优先级。

安全建模 + LLM 行为

⚖本套与"代码导览"的区别

面试官不会问你"某行代码怎么写"。他会问你"这个设计在并发 / 崩溃 / 成本下为什么不崩"。下表是这套文档刻意做的取舍。

维度代码导览式文档本套（面试视角）
回答的问题"代码长什么样？在哪个文件？""为何这样设计？不这样会怎样？"
抽象层级函数 / 行号 / 类型签名分层 / 职责 / 边界 / 不变式
示例深度demo 级 toy 例子生产级取舍：缓存失效 / 崩溃恢复 / 成本爆炸
叙事单向陈述面试官追问 ↔ 面试者拆解 双视角
巩固方式无每页 🎯 面试追问（多层深挖）
📌 为什么"屏蔽代码"反而学得更深

代码是设计的产物，不是原因。盯着产物学，你只能记住"它现在长这样"；盯着原因学，你能推出"换我也会这么设计"。后者才是面试真正要考的系统设计成熟度。

🎓如何用这套准备面试

这套文档的设计目标不是"读完就懂"，而是"被追问到答不出才真懂"。建议这样用。

1

先读"问题先于方案"

每篇第 2 段。先停 30 秒想：换我，没这设计会怎样？带着自己的答案再读方案，对比差距——这比直接读方案深 3 倍。

2

用"生产级取舍"练反向论证

每篇第 4 段的"不这么做的代价"。面试官最爱追问"那如果不这样呢？"——预先练好反向论证，追问就追不倒你。

3

对着"双视角"练表达

第 5 段。面试者拆解那部分是表达模板：抽象定位 → 约束 → 方案 → 代价 → 未来演化。背下这个五段式。

4

🎯 面试追问必须做完

每篇末尾。这是模拟面试官——它会一层层追问到你答不出。答不出说明那里没真懂，回上面重读。评分用自评，诚实最重要。

🎯 关于"面试追问"组件

每条线索是根问题 → 揭示参考答案 → 自评 → 解锁更深一层追问，模拟真实面试官的"打破砂锅问到底"。进度存 localStorage，刷新不丢。这是这套文档区别于一切静态教程的核心。
